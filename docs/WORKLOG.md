# План доработок витрины EVGENIY APPLE

Документ фиксирует состояние прототипа и план приведения к актуальной версии ТЗ
(ревизия: двухуровневая шапка, карусель первым экраном, упрощение текстов).
Обновляется по мере выполнения групп изменений.

## Текущее состояние (что сделано)

- **Дизайн-система**: палитра из ТЗ (`#F7F7F3` / `#FFFFFF` / `#171717` / `#737373` / `#E5E5E0`), акцент — глубокий зелёный `#2F5D3A`, золотой — только малый сигнал (`--color-signal`), Manrope, радиусы 16/24 px, минимальные тени, глобальный `prefers-reduced-motion`.
- **Фирменная загрузка** (`components/loading/DartLoader.tsx`): кольцевая мишень, 8 мягких дротиков, финальный сбор в знак бренда; прогресс от реальной готовности (шрифты + критическое изображение), порог показа 400 мс, лимит 2,5 с, один показ за сессию, reduced-motion — статичный знак и полоса. Знак — `BrandMarkPlaceholder`. Debug-режим `?hold=N` доступен на любой странице.
- **Товарная карусель** (`components/carousel/FeaturedCarousel.tsx`): desktop — плавное непрерывное движение, hover-пауза, активная карточка +5%; mobile — swipe со scroll-snap; автодвижение останавливается после первого взаимодействия; карточки из общего слоя данных (цена «от», цвета, статус, «Выбрать»).
- **Данные и конфиг** (группа A): `lib/site.ts` — контакты-плейсхолдеры без фейковых ссылок (`phone: null` → шаблон «+375 (__) ___-__-__ · уточняется», Telegram/Instagram → «· скоро») и навигация одним массивом `NAV_LINKS` (8 пунктов по ТЗ); `lib/catalog.ts` — карусель только из доступных (`in-stock`/`on-order` + featured), `getActualOffers()` без пересечения с каруселью, `queryProducts()` с фильтрами и сортировкой, поле `addedAt` у товаров.
- **Бренд-заглушка** (группа B): `components/brand/BrandMarkPlaceholder.tsx` — текстовый знак EVGENIY APPLE, размер задаётся внешним font-size; заменяется на SVG заказчика переписыванием одного компонента. Старый `BrandMark.tsx` удалён.
- **Двухуровневая шапка** (группа C, `components/layout/Header.tsx`): служебная строка — телефон и мессенджеры из конфига (убирается при прокрутке), основная строка — знак + 8 пунктов + рабочий поиск (`/catalog?focus=1`). Desktop ≥1280px: покой 109 px, компакт 57 px; ниже breakpoint — выпадающее меню, высота 64 px. «iPhone» в навигации нет.
- **Главная по новой структуре** (группа D): карусель — первый блок (заголовок + строка + кнопка «Каталог») → категории → полоса доверия → б/у → Trade-in → актуальные предложения (без дублей карусели) → покупка/доставка/оплата/цена → гарантия → ремонт → обо мне (фото владельца — единственное на странице, lazy) → факты → контакты и соцсети → FAQ. Текстовый hero и `FounderTrustBlock` удалены.
- **Каталог** (группа E, `app/catalog/page.tsx` + `components/catalog/CatalogControls.tsx`): поиск `?q=` (модель, серия, цвет, артикул), фильтры `?storage= ?color= ?availability= ?maxPrice=`, сортировка `?sort=` (рекомендации/новизна/цена ↑↓); состояние в URL, чипсы категорий, фильтры работают без JS (`<details>` + GET-форма); пустая выдача — сброс фильтров + «Задать вопрос».
- **Тексты и маршруты** (группа F): «Смотреть каталог» → «Каталог», «Задать вопрос Евгению» → «Задать вопрос»; новые `/repair` и `/faq`; Footer — плейсхолдеры без `t.me/objective_demo` и фейкового телефона, ссылки на новые разделы; `FounderContactDock` — единственная плавающая кнопка, при пустом Telegram ведёт на `/contacts?topic=question`; `FounderContactSlot` — встроенный контактный слот на служебных страницах; контакты на `/contacts` из одного конфига.
- **Убраны временные демо**: `/boot-demo` и `/api/slow-image` удалены (debug `?hold=N` остался в прелоадере).
- **Проверено**: tsc / eslint / next build (15 маршрутов) — зелёные; 375/1280/1440 без горизонтального скролла; порядок секций и работа фильтров проверены в браузере; карусель и загрузка без изменений.
