# План доработок витрины EVGENIY APPLE

Документ фиксирует состояние прототипа и план приведения к актуальной версии ТЗ
(ревизия: двухуровневая шапка, карусель первым экраном, упрощение текстов).
Обновляется по мере выполнения групп изменений.

## Текущее состояние (что сделано)

- **Дизайн-система**: палитра из ТЗ (`#F7F7F3` / `#FFFFFF` / `#171717` / `#737373` / `#E5E5E0`), акцент — глубокий зелёный `#2F5D3A`, золотой — только малый сигнал (`--color-signal`), Manrope, радиусы 16/24 px, минимальные тени, глобальный `prefers-reduced-motion`.
- **Фирменная загрузка** (`components/loading/DartLoader.tsx`): кольцевая мишень, 8 мягких дротиков, финальный сбор в знак бренда; прогресс от реальной готовности (шрифты + критическое изображение), порог показа 400 мс, лимит 2,5 с, один показ за сессию, reduced-motion — статичный знак и полоса.
- **Товарная карусель** (`components/carousel/FeaturedCarousel.tsx`): desktop — плавное непрерывное движение, hover-пауза, активная карточка +5%; mobile — swipe со scroll-snap; автодвижение останавливается после первого взаимодействия; карточки из общего слоя данных (цена «от», цвета, статус, «Выбрать»).
- **Главная**: полоса доверия, категории, б/у паспорта, Trade-in, «Как проходит покупка», 404.
- **Каталог** (`app/catalog/page.tsx`): сетка по категории из URL `?category=`, счётчик товаров; карточка товара — каркас с галереей и характеристиками.
- **Личный бренд**: двухколоночный hero с фото владельца (WebP из реальной фотографии, арка + зелёная форма + золотой штрих), фиксированная кнопка «Задать вопрос» с аватаром и индикатором, текстовый логотип EVGENIY APPLE, конфиг контактов `lib/site.ts`.
- **Проверено**: tsc / eslint / next build — зелёные; ширины 320–1440 без горизонтального скролла; лицо на фото не обрезается; карусель и загрузка работают.

## План доработок (актуальная ревизия ТЗ)

### A. Данные и конфиг
- `lib/site.ts`: контакты-плейсхолдеры без фейковых ссылок — `phone: +375 (__) ___-__-__`, `telegram: ссылка ожидается`, `instagram: ссылка ожидается`; навигация одним массивом (8 пунктов строго по ТЗ).
- `lib/catalog.ts`: фильтр карусели — только «В наличии» / «Под заказ» и флаг показа; выборка «актуальных предложений» без пересечения с каруселью.

### B. Бренд-заглушка
- Новый `components/brand/BrandMarkPlaceholder.tsx` (текстовый EVGENIY APPLE, простая замена на SVG).
- Подключить в `DartLoader` и шапке вместо прямых ссылок на знак.

### C. Шапка (двухуровневая)
- Верхняя служебная строка: телефон-плейсхолдер + Telegram/Instagram (из конфига, без рабочих ссылок).
- Основная строка: логотип + навигация строго: Новые устройства, Б/У устройства, Trade-in, Доставка и оплата, Гарантия, Ремонт и обслуживание, Обо мне, Контакты.
- Высота desktop 108–122 px, компакт при скролле; mobile 64–72 px; выпадающее меню ниже breakpoint.
- Убрать «iPhone» из навигации; поиск — только рабочий (ведёт в поиск каталога).

### D. Главная (новый порядок)
- Удалить текстовый hero и блок «Можно спросить Евгения» (`components/founder/FounderTrustBlock.tsx`).
- Порядок: карусель (короткий заголовок + одна строка + кнопка «Каталог») → каталог/категории → полоса доверия → б/у → Trade-in → актуальные предложения (без дублей карусели) → покупка/доставка/оплата/цена → гарантия → ремонт → обо мне (фото + факты, одна кнопка) → отзывы/факты → контакты и соцсети → FAQ.
- Фото Евгения только в «Обо мне».

### E. Каталог
- Поиск (модель, серия, артикул, ключевые слова) в URL `?q=`.
- Фильтры: модель, память, цвет, состояние, наличие, цена; сортировка: рекомендации, новизна, цена ↑/↓.
- Пустая выдача: сброс фильтров + «Задать вопрос» менеджеру.

### F. Тексты и маршруты
- Замены по всему интерфейсу: «Смотреть каталог» → «Каталог», «Задать вопрос Евгению» → «Задать вопрос».
- Новые служебные маршруты: `/repair` (Ремонт и обслуживание), `/faq`.
- Одна плавающая точка входа «Задать вопрос» сохраняется без изменений.
